搜索过去会话的观察和经验，找出相关上下文。封装 `memory_smart_search` 和 `memory_lesson_recall` MCP 工具。

## 用法

```
/recall [查询]
```

## 执行说明

1. 用该查询调用 `memory_smart_search`，`limit: 10`（混合 BM25 + 向量 + 图谱搜索）。
2. 用同一个查询调用 `memory_lesson_recall`，`limit: 5`（经验搜索）。
3. 合并结果并展示给用户：
   - 按会话分组
   - 每条观察展示类型、标题和叙述内容
   - 突出展示高重要度（>= 7）的观察
   - 单独展示经验，并附置信度分数
4. 如果没有结果，建议 2-3 个替代搜索词。
5. **绝不编造结果。** 只展示 MCP 工具实际返回的内容。
